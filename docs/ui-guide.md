# 网页使用指南

1. 在 `/login` 登录。数据库没有账号时可注册第一个账号；后续注册由 `ALLOW_REGISTRATION` 控制。
2. 创建项目，填写的是本项目预算上限，单位为人民币元。项目是数据隔离边界。
3. 上传 TXT（syslog、log4j、Apache error）或逐行 JSON，单文件最多 10 MiB。可勾选 IP 脱敏；默认保留 IP 供排障。上传后显示后台排队/解析进度，完成后显示解析、坏行、脱敏统计；刷新页面可恢复最近任务，失败可点击“重试解析”。重复内容不会重复入库。
4. 选择数据源、时间窗、严重度、事件类型和消息关键词。未填写的时间窗覆盖该数据源全部已上传事件；关键词按字面包含匹配。
5. 点击开始分析，从状态页进入报告。也可回项目页的分析记录查找历史报告；Run 和报告链接支持直接打开，不需要手工添加项目参数。
6. 正常日志显示规则统计、时间范围和 Top 分组，并明确标注模型未参与。没有匹配事件会提示检查筛选条件。模型失败时保留规则结果，状态和原因单独显示。
7. 结论中的“查看证据”可展开脱敏后的事件时间和内容。`fact` 是有有效事件证据的事实；`inference`、`possibility` 都不能直接当成根因。
8. 项目页“事件分组与事故记忆库”可浏览分组、展开成员事件、查看事故来源报告。事故是启发式归并，不是因果判定。
9. 在报告或知识页审核候选。编辑、确认、标记误报和丢弃都在当前项目内生效。候选未经确认不会进入后续分析。
10. “退出”由服务器清除登录 Cookie；已有 Bearer token 仍按自身有效期处理。

同格式文件默认复用一个数据源，因此“数据源”可能包含多次上传；时间窗和过滤条件可以进一步缩小范围。需要独立来源时可通过 API 先建数据源并在上传时指定其 ID。

服务异常时参见 [运维手册](runbook.md)，功能边界见 [已知限制](limitations.md)。
